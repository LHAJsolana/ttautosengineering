# Ce que P0700 signifie réellement avant d'acheter une voiture d'occasion

P0700 signifie que le contrôleur de transmission a demandé au contrôleur du moteur d'allumer le témoin. Il n'identifie **pas** la pièce défectueuse. Un scanner de base peut afficher uniquement P0700 tandis que le code utile reste à l'intérieur du module de commande de transmission.

## Scannez le bon module

Utilisez un équipement capable d'entrer dans le contrôleur de boîte de vitesses et d'enregistrer chaque code stocké, en attente et historique. Enregistrez les données d'arrêt sur image avant que quoi que ce soit ne soit effacé. Les codes de rapport, de pression, de solénoïde, de température et de communication conduisent à des voies de réparation très différentes.

<Callout type="warn" title="Un code messager n'est pas un diagnostic">
N'acceptez pas « il suffit d'un capteur » sans le code spécifique à la transmission, les données en direct et la preuve d'une réparation terminée.
</Callout>

## Testez la voiture à froid et à chaud

Vérifiez l'engagement en marche arrière et en marche arrière, les changements de vitesse légers, le kickdown, la sélection manuelle et le comportement une fois le liquide chaud. Surveillez les engagements retardés, les régimes évasés, les changements de vitesse brusques, les frissons ou le mode boiteux. Un court test à froid peut masquer une perte de pression qui n'apparaît qu'à chaud.

## Vérifiez la tension et les preuves de service

Une faible tension de batterie peut créer des défauts de réseau et de contrôle, mais cela doit être prouvé plutôt que supposé. Examinez les factures de services fluides et confirmez que les spécifications correctes ont été utilisées. Le « fluide à vie » ne prouve pas que l’état n’a plus d’importance.

## Règle d'achat

Traitez un P0700 inexpliqué comme un risque de transmission non résolu. Si le vendeur n'autorise pas une analyse complète du module et un essai routier prolongé, évaluez la voiture comme si une réparation importante de la boîte de vitesses pouvait être nécessaire ou partez. Utilisez la [bibliothèque de codes d'erreur](/fault-codes) pour interpréter le code sous-jacent une fois qu'il est connu.
